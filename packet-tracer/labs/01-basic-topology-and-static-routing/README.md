## Objective

Build a small multi-router topology in Packet Tracer, address each
segment, and configure static routes so that end devices on different
networks can reach each other.

- Basic router and switch configuration (hostname, interfaces,
  passwords).
- IP addressing and subnetting.
- Static routing (`ip route`).
- Basic connectivity verification (`ping`, `traceroute`,
